# 🎮 Gerenciador de Jogos

Projeto desenvolvido para praticar o desenvolvimento de aplicações web utilizando Java e Spring Boot.

O sistema permite cadastrar e gerenciar jogos de videogame, com informações como título, ano, plataforma, disponibilidade e observações.

## ⚙️ Funcionalidades

- Listar jogos cadastrados.
- Cadastrar novos jogos.
- Editar informações dos jogos.
- Excluir jogos.
- Validar campos obrigatórios.
- Armazenar dados em banco de dados.

## 💻 Tecnologias utilizadas

- Java
- Spring Boot
- Spring Data JPA
- H2 Database
- JavaScript
- HTML
- CSS
- Maven

## 🚀 Objetivo

Projeto acadêmico desenvolvido durante o curso de Análise e Desenvolvimento de Sistemas (ADS), com foco na prática de Java, integração com banco de dados e operações CRUD.
